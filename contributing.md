# 🤝 Contributing Guide

Thanks for your interest in contributing to this project!

This repository is an active **IoT + Machine Learning learning project**, and contributions of all sizes are welcome.

---

## 🛠️ Ways to Contribute

You can contribute by:
- Improving code quality or structure
- Enhancing the web dashboard UI
- Optimizing or extending the ML model
- Adding support for new sensors or ESP32 boards
- Improving documentation
- Reporting bugs or issues

---

## 📋 Before You Start

Please ensure that:
- Your changes are clear and readable
- Existing functionality continues to work
- New features are documented if needed

---

## 🔀 Contribution Workflow

1. Fork the repository
2. Create a new feature branch
   ```bash
   git checkout -b feature/my-feature
   ```
3. Commit your changes
   ```bash
   git commit -m "Add: brief but clear description"
   ```
4. Push to your fork
5. Open a Pull Request

---

## 🧪 Testing Guidelines

If your contribution affects:
- **ESP32 firmware** → verify flashing and sensor reading
- **Flask server** → test API endpoints and dashboard loading
- **ML pipeline** → ensure preprocessing and training still run successfully

Best effort testing is appreciated.

---

## 🧠 Project Philosophy

This project is meant to be a **learning playground** combining:
- Internet of Things (IoT)
- Machine Learning
- Web-based visualization

Clarity, maintainability, and learning value are preferred over unnecessary complexity.

---

Thank you for contributing 🚀
